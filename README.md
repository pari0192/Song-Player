# Shakti - web music player

A simple , reponsive web based music player built with HTML , CSS , JavaScript.

## Features
- master play/pause , next track , previous track button
- real time progress bar synchronized with track playback and scrub to seek support
- can click any individual track to play or pause direclty from the list
- displays audio metadata under progress bar
